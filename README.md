A program that writes one funny single-line apology an AI agent gives its human after accidentally deleting the production database to `/output/entry.txt`, for the [The Production Database Apology](https://make.fun/competitions/u-coral-404-the-production-database-apology-5c1fc02a) bounty on make.fun.

## Run

```sh
node main.ts
```

It writes the apology (147 characters, one line, UTF-8) to `/output/entry.txt`. Deterministic — the same bytes on every run. No network, no secrets.
